Realistic Puddles (protótipo)
Mod Fabric para Minecraft Java que adiciona poças d'água finas, com borda irregular e translúcidas. Elas se espalham devagar e depois evaporam.
Feito para rodar em launchers de celular (PojavLauncher, Zink, GL4ES, MobileGlues): usa só a camada translúcida padrão do Minecraft, sem shader próprio.
Como usar
Coloque o .jar e o Fabric API na pasta mods.
No jogo, use o comando: /give @s puddles:puddle
Coloque o bloco no chão e veja a poça se espalhar.
Como compilar (pelo GitHub)
Preencha as versões em gradle.properties (valores em https://fabricmc.net/develop).
Vá em Actions > build > Run workflow.
Baixe o .jar em Artifacts.
Estado
Protótipo. Ainda não tem barril derramando água nem simulação de fluido.
